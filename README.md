# ASD Cognition

Advanced system design (ASD) course project.

## Installation

1. Clone the repository and enter it:

    ```sh
    $ git clone git@github.com:zahitz/asd_cognition.git
    ...
    $ cd asd_cognition/
    ```

2. Run `uv sync` to download the dependencies, or if you don't have `uv`, run the installation script:

    ```sh
    $ uv sync # Or `./scripts/install.sh`
    ...
    $ source .env/bin/activate
    [asd] $ # you're good to go!
    ```

3. To check that everything is working as expected, run the tests:

    ```sh
    $ uv run pytest tests/ # Or `python -m pytest tests/`
    ...
    ```
